## 五、关键经验教训（重要反思）

**昨天 debug 的真相**：
- 用户反馈 vocab-pwa 打不开
- 我**没去对比 lucky-pick**（一直能看），直接钻进 Clash/DNS/TUN 排查
- **耗了好几小时**查 fake-IP、DoH、launchd
- **实际上**所有"网络问题"都是**代码 bug**：
  1. `escapeHtml is not defined` → 白屏
  2. SW 的 `?v=` URL 让 SW 返回坏缓存
  3. `cache.addAll` 包含 CDN，内置浏览器屏蔽外网 CDN → install 失败
- lucky-pick 没这些 bug，**所以一直能看**

**教训**：
- **PWA 项目出问题，先对比同网络下另一个能用的项目**（5 秒定位"代码 vs 网络"）
- 别钻进单条线索前先验证"是不是这层的问题"
